# ToonPace 0.1.5

선택한 웹툰 앱에서 기기 내 글자 인식으로 읽기 간격을 조절하는 Android 실험 앱입니다.

## 다운로드

- [휴대폰 테스트 APK](downloads/toonpace-0.1.5-debug.apk)
- [전체 소스 ZIP](downloads/toonpace-0.1.5-source.zip)
- [체크섬](downloads/SHA256SUMS.txt)

Android 11 이상. 이전 0.1.1~0.1.4 APK와 동일한 테스트 인증서로 서명합니다. Play 등록용 서명이나 심사 승인을 의미하지 않습니다.

## 0.1.5 변경

- 브라우저의 `[17 / 총60] → 끝 → 다음화 › → ‹ 이전화` 형태를 회차 종료 영역으로 인식합니다. 각 표시가 가까이 세로로 정렬되어 있는지 함께 확인합니다.
- ‘끝’이라는 대사 하나로 회차를 넘기지 않으며 오류 신고·이전화·홈·목록·회차 버튼은 이동 대상으로 선택하지 않습니다.
- 3초 뒤 탭하기 전에 같은 회차 번호와 종료 영역인지 다시 확인합니다. `[60 / 총60]`처럼 마지막 회차가 명시되면 남아 있는 다음 화 버튼도 누르지 않습니다.
- `⋮ → 다음 화 인식 확인`에 `끝 표시 · 회차 17/60` 같은 진단을 표시합니다. 브라우저로 읽으려면 앱 선택에서 Chrome 등 사용하는 브라우저를 체크하세요.
- 제공된 두 휴대폰 사진에서 읽은 문구·좌표를 회귀 검사에 추가했습니다. 실제 휴대폰의 OCR/클릭 동작 검증은 남아 있습니다.

## 0.1.4 변경

- 카카오페이지 화면에서 확인한 `다음화 무료로 보기`, `다음화 보기`와 여러 회차 이동 표현을 인식합니다. OCR의 띄어쓰기·줄바꿈, 접근성 버튼 설명 및 명확한 다음 회차 ID도 확인합니다.
- 다음 화 카드 아래 `이 작품과 함께보는 웹툰` 제목이 보이면 회차 하단으로 판단합니다. 추천 목록의 마지막까지 스크롤해야 했던 조건을 수정했습니다. 3초 뒤 버튼 위치·하단 구조·앱·결제 안내를 다시 확인합니다.
- 원작소설 배너, 추천 카드, 일반 화살표를 다음 회차로 고르지 않습니다. 서로 떨어진 다음 회차 후보가 여러 개 있으면 자동 선택을 보류합니다. 접근성 클릭을 제공하는 버튼은 그 동작을 우선 사용합니다.
- `⋮ → 다음 화 인식 확인`에서 현재 버튼 문구, 인식 방법, 회차 하단 확인 여부를 볼 수 있습니다. 확인 기능은 자동으로 클릭하거나 스크롤하지 않습니다.
- 명확한 최대 스크롤 위치에서 반복해서 멈춰 있으면 추천 영역의 애니메이션 때문에 종료 판단이 계속 미뤄지지 않도록 했습니다.
- 툰페이스 설정 화면 하단에 광고 슬롯과 생명주기 연결점을 준비했습니다. debug에서는 미리보기만 표시하며, release에서는 공급자가 연결되기 전까지 숨깁니다. 실제 광고 SDK·ID·광고 요청은 없습니다. 웹툰 화면 위에는 광고를 표시하지 않습니다.

현재는 사전 학습된 한국어 ML Kit OCR을 사용합니다. 새 이미지 딥러닝 모델을 학습한 버전이 아닙니다. 제공된 사진의 문구와 위치를 검사 사례에 반영했으며, 실제 픽셀 OCR·휴대폰 클릭 검증은 남아 있습니다. [인식 방식과 추가 학습 계획](docs/BUTTON-RECOGNITION.md).

## 휴대폰 확인

1. 접근성 동의 후 사용할 앱을 선택합니다. 브라우저로 읽는 경우 해당 브라우저도 선택합니다.
2. 무료 회차 마지막에서 `⋮ → 다음 화 인식 확인`을 눌러 인식 결과를 확인합니다.
3. 다음 화 자동 이동을 켜고 ▶를 누릅니다. 이동 대기 중 화면을 누르거나 Ⅱ를 누르면 정지합니다.
4. 다음 회차가 열리고 원작소설·추천 카드가 열리지 않는지 확인합니다.

첫 터치는 정지에 사용되며, 멈춘 뒤 다시 터치하면 웹툰 앱을 조작합니다. 자동 제스처를 주입하는 짧은 동안에는 터치 감지가 제한될 수 있으므로 별도 Ⅱ 버튼도 유지합니다. ⋮는 끌어 이동할 수 있고 −/+로 0.5~5배 속도를 조절합니다. 기기의 OCR 처리시간 때문에 실제 이동량이 정확히 5배가 되는 것은 아닙니다.

자동 구매는 대상 서비스에서 먼저 끄고 무료 접근 가능한 회차에서 사용하세요. 결제·대여·로그인·광고 시청 안내가 보이면 중단합니다.

## 빌드

Android Studio에서 루트 폴더를 열고 SDK Platform 35 / Build-Tools 35.0.0을 설치합니다. Gradle 8.11.1, JDK 17 이상을 사용합니다.

- `sh test-core.sh`
- `./gradlew :app:assembleDebug :app:lintDebug`
- `./gradlew :app:bundleRelease` — 업로드 서명 환경변수가 없으면 미서명 AAB 생성

Windows에서는 SDK를 Android Studio GUI로 설치한 뒤 IDE 또는 build-windows.cmd를 사용합니다. APK는 `app/build/outputs/apk/debug/app-debug.apk`, AAB는 `app/build/outputs/bundle/release/app-release.aab`에 생성됩니다. 실행한 검사는 [TEST-RESULTS.md](TEST-RESULTS.md)에 기록합니다.
