# ToonPace 0.1.2

카카오페이지에서 회차 중간에 멈추는 끝 판정, 글자가 적을 때 속도 차이가 사라지는 문제, 화면을 가리는 조작부를 개선한 Android 테스트 앱입니다.

## 사용 방법

- 작은 ▶ 버튼으로 시작하고 Ⅱ 버튼으로 정지합니다.
- ⋮를 끌면 조작부를 옮길 수 있습니다. ⋮를 누르면 학습, −/+, 설정, 닫기 메뉴가 열립니다.
- −/+는 읽기 대기 중인 시간과 다음 스와이프 시간을 조정합니다. 대기시간은 기기 OCR 처리 속도에 따라 정확한 배속과 다를 수 있습니다.
- 다음 화 자동 이동은 초기 테스트에서는 꺼두세요.

## 변경 내용

- 비슷한 화면 두 장만으로 끝을 판단하던 조건을 제거했습니다. 스크롤 이동 이벤트가 있으면 비슷한 그림이나 여백에서도 계속 진행합니다.
- 이동 정보가 없을 때는 같은 화면을 반복 확인합니다. 다음 화 버튼이 있으면 4번, 버튼도 없으면 10번의 이동 실패 후 중단합니다. 이는 회차 끝을 보장하는 판정이 아니며, 이동 불가/로딩/이벤트 미지원 상황에서는 사용자가 확인해야 합니다.
- 지연 도착한 스크롤 이벤트만으로 수동 조작을 확정하지 않습니다. 실제 클릭/터치 이벤트는 중단에 사용하지만 모든 앱의 빈 화면 터치를 감지할 수는 없습니다. 확실한 중단 방법은 Ⅱ 버튼입니다.
- 읽기 최소 대기시간을 1400ms에서 350ms로 조정하고, 스와이프 시간에도 0.5~2배 설정을 적용했습니다.
- 기본 조작부는 ▶/Ⅱ 및 ⋮ 두 버튼만 표시하며, 큰 메뉴는 필요할 때 엽니다.

## 빌드와 검증

Android Studio에서 프로젝트 루트를 열고 SDK Platform 35 및 Build-Tools 35.0.0을 설치합니다. Gradle 8.11.1과 JDK 17 이상이 필요합니다. `./gradlew :app:assembleDebug :app:lintDebug`로 검증할 수 있습니다. Windows에서는 SDK를 GUI로 설치한 뒤 Android Studio 또는 `build-windows.cmd`를 사용합니다.

`sh test-core.sh`로 읽기 속도, 중단 판정, 스크롤 끝 후보 판정 검사를 실행합니다. 상세 실행 결과와 실기기 미검증 범위는 TEST-RESULTS.md를 참고하세요.
