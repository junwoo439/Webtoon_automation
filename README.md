# ToonPace 0.1.1

이 소스는 업로드한 최신 프로젝트를 기준으로 자동 스크롤 중단 판정을 수정한 실험 버전입니다.

## Windows에서 빌드

1. 기존 프로젝트를 백업하고 이 프로젝트를 별도 영문 경로에 풉니다.
2. Android Studio에서 프로젝트 루트를 엽니다.
3. SDK Manager에서 Android SDK Platform 35 및 Build-Tools 35.0.0을 설치합니다.
4. Gradle JDK는 Android Studio 내장 JDK 17 이상을 사용합니다.
5. Gradle 동기화 후 Build 메뉴에서 APK 생성 기능을 실행합니다.
6. 결과 파일은 `app/build/outputs/apk/debug/app-debug.apk`입니다.

`build-windows.cmd`도 설치된 SDK를 확인하고 Gradle 8.11.1로 디버그 APK를 빌드합니다. Windows에서 차단되었던 sdkmanager는 호출하지 않습니다. Gradle 다운로드는 공식 SHA-256을 확인합니다.

## 수정 내용

- 마우스 클릭/길게 누르기 접근성 이벤트를 수신합니다.
- 자동 제스처 완료 후 관성 스크롤 이벤트가 잠잠해질 때까지 기다립니다(최대 약 6초). 고정 1050ms 뒤 발생한 자기 스크롤을 즉시 수동 조작으로 판단하던 문제를 줄입니다.
- 읽기 대기 중 전달된 클릭/터치/스크롤 이벤트로 일시정지합니다. 다음 화 로딩 대기 중에도 자체 제스처 보호 구간이 지나면 직접 조작을 감지합니다.
- 이전 실행의 제스처 완료 콜백이 다시 시작한 실행에 영향을 주지 않도록 확인합니다.
- 앱/기기에 따라 모든 빈 영역 터치가 접근성 이벤트로 전달되지는 않습니다. 확실하게 멈추려면 떠 있는 **Ⅱ 정지** 버튼을 누르세요.

## 휴대폰 설치

Android 11 이상이 필요합니다. 디버그 APK는 테스트용 서명입니다. 기존 설치본과 서명 키가 다르면 업데이트할 수 없습니다. 필요한 설정을 기록한 뒤 기존 앱을 삭제하고 설치하면 앱 데이터와 학습 내용은 사라집니다.

Play 프로텍트가 설치를 차단하면 이 빌드가 차단을 해제한다고 가정하지 마세요. 서명/버전 변경은 Google의 판정을 변경한다는 보장이 없습니다. Play 프로텍트 차단 이유는 확인되지 않았으며, 필요하면 개발자가 공식 검토 절차를 진행해야 합니다.

## 기능 확인

다음 화 자동 이동은 끈 상태에서 테스트하세요. 긴 테스트 페이지에서 3회 이상 자동 스크롤, Ⅱ 정지, 재시작, 직접 클릭/스크롤, 다른 앱으로 전환, 접근 동의 철회를 확인하세요. 유료 서비스나 실제 계정 없이 먼저 확인하세요. 결제 안내 감지는 키워드 기반이며 모든 화면을 판별한다는 보장이 없습니다.

## 테스트

`sh test-core.sh`로 핵심 로직 및 중단 판정 테스트를 실행합니다. Android 화면 조작 테스트와 Play 프로텍트 검증은 별도입니다. 상세 실행 결과는 TEST-RESULTS.md를 참고하세요.
