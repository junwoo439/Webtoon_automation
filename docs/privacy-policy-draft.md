## 처리 목적과 정보

툰페이스는 사용자가 선택한 앱에서 읽기 속도를 조절하고 스크롤·다음 회차 이동을 보조합니다. 사용자가 접근성 기능에 동의하고 읽기를 시작하면 현재 화면의 글자·버튼 정보와 스크린샷을 기기 안에서 처리합니다. 화면의 대사와 스크린샷은 파일로 저장하거나 서버에 전송하지 않습니다. 인식 확인 기능은 현재 버튼 문구와 인식 방법을 잠시 표시하며 별도 기록을 남기지 않습니다.

선택한 앱의 식별자, 접근 동의 여부, 속도 및 다음 화 설정, 앱별 학습 속도 수치와 학습 횟수는 앱 내부 저장소에 보관합니다. 현재 버전은 인터넷 접근 권한, 광고 SDK, 분석 SDK를 추가하지 않으며 외부 서버로 데이터를 전송하는 기능이 없습니다. 글자 인식은 번들된 ML Kit 모델을 사용합니다.

## 보관과 삭제

앱 안에서 학습 초기화와 접근 동의 철회를 할 수 있습니다. 접근 동의 철회는 자동 처리를 중단하며 학습 자료의 삭제와는 별개입니다. 앱 데이터 삭제 또는 앱 제거 시 저장된 설정과 학습 수치가 제거됩니다. Android 설정에서 접근성 권한을 언제든 끌 수 있습니다.

## 광고

현재 테스트 화면의 ‘광고 영역 미리보기’는 실제 광고가 아니며 광고 요청을 하지 않습니다. 이후 광고를 도입할 경우 사용하는 광고 사업자, 처리 정보, 목적과 동의/선택 방법을 본 방침 및 Google Play 데이터 보안에 반영합니다. 웹툰 화면·대사·접근성 정보는 광고 타기팅에 사용하지 않습니다.

## 문의와 변경

처리 정보와 권리 행사 문의는 위 운영자 연락처로 받습니다. 기능 또는 처리 방식 변경 시 시행일과 내용을 갱신해 안내합니다.
