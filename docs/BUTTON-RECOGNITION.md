# 다음 회차 인식과 이미지 학습

## 0.1.4에서 확인한 원인

사용자가 제공한 화면에는 `다음화 무료로 보기`, `다음화 보기`, `이 작품과 함께보는 웹툰`이 있습니다. 기존 정규식은 `다음화 무료로 보기`를 거부했습니다. 또한 다음 회차 카드 **아래**에 추천 작품이 있어서 페이지 전체의 끝을 회차 끝으로 보는 조건이 맞지 않았습니다.

이번 버전은 다음 회차 문구, 접근성 버튼 설명/ID, 가까운 두 줄 OCR 결과를 확인합니다. 원작소설 링크·추천 작품·일반 화살표는 다음 회차로 간주하지 않습니다. 같은 목적의 서로 다른 버튼이 여러 개 보이면 자동 선택을 보류합니다.

다음 회차 카드 아래의 정확한 추천 영역 제목이 보이면 회차 하단으로 판단하고, 페이지 맨 아래까지 더 스크롤하지 않고 3초 뒤 다시 버튼/하단/앱/결제 문구를 확인합니다. 이 하단 구조가 없는 다른 뷰어는 반복 스크롤 및 화면 끝 확인을 계속 사용합니다. 버튼 자체의 접근성 클릭을 우선하고, 제공되지 않으면 확인된 글자 위치를 탭합니다.

`⋮ → 다음 화 인식 확인`은 현재 인식 문구, 인식 방법, 회차 하단 확인 여부 또는 중단 이유를 보여 줍니다. 이 동작은 스크롤하거나 버튼을 누르지 않습니다. 실제 사진의 픽셀을 ML Kit에 넣은 테스트는 이번 환경에서 실행하지 못했습니다. 테스트의 문구·좌표 사례는 사진에서 사람이 읽어 옮긴 것이므로 OCR 정확도 수치가 아닙니다.

## 딥러닝 적용 범위

현재 한국어 글자 인식은 **사전 학습된 ML Kit OCR 모델**을 사용합니다. 이번에 제공된 사진으로 새 신경망을 학습하거나 정확도가 검증된 모델을 만든 것은 아닙니다. 현재 원인은 주로 OCR 이후의 문구 허용 조건과 회차 끝 조건이었으며, 새 모델을 넣어도 이 조건을 고치지 않으면 같은 문제가 남습니다.

추가 학습을 하려면 버튼의 모양이나 아이콘을 인식하는 모델을 별도로 만들고 실제 화면으로 평가해야 합니다. 이번에 두 작품에서 제공된 화면들은 문구와 하단 구조를 재현하는 데 사용했습니다. 이처럼 비슷한 구조의 다음 화 화면만으로 학습·평가하면 결제·광고·로그인 화면에서의 오인식을 측정할 수 없습니다. 해당 음성 사례와 별도 검증용 화면이 필요합니다.

### 다음 학습 단계

1. 사용 권한이 있는 실제 화면을 확보합니다. 서로 다른 작품, 앱 버전, 테마, 글자 크기, 화면 비율에서 무료 다음 회차, 일반 다음 회차, 유료/대여, 로그인, 광고, 원작소설, 추천 작품, 다음 버튼 없는 중간 화면을 포함합니다. 개인정보가 들어간 알림·계정 정보는 제거합니다.
2. 버튼 전체 영역과 종류를 주석 처리합니다. 다음 버튼이 아닌 화면도 음성 사례로 포함합니다. 합성 이미지나 크기/밝기 변형은 보조 학습에만 사용하고 실제 검증 화면을 대체하지 않습니다.
3. 작품/촬영 세션 단위로 train/validation/test를 먼저 분리합니다. 같은 화면을 변형한 복사본이 평가 세트에 섞이지 않도록 합니다. 데이터 규모는 실제 다양성과 오인식률을 보고 늘립니다.
4. 소형 객체 검출 모델을 전이 학습하고 별도 실화면에서 정밀도·재현율·버튼별 혼동, 특히 유료/광고 버튼 오탐을 측정합니다. Android용 TFLite/LiteRT 모델로 변환하고 기기 지연과 메모리를 측정합니다.
5. 처음에는 모델 결과를 ‘인식 확인’에만 표시하는 방식으로 평가합니다. 모델의 후보가 기존의 명시적 동의·대상 앱·결제 차단·회차 종료·재확인 조건을 우회하지 않도록 합니다. 기준을 만족하지 않으면 기존 인식 또는 수동 조작을 유지합니다.

원본 스크린샷은 개인정보와 제3자 저작물이 포함될 수 있으므로 자동으로 공개 저장소에 커밋하지 않습니다. 이번 저장소에는 원본 사진을 추가하지 않았습니다.

## 휴대폰에서 확인

1. 무료 회차 마지막에서 `⋮ → 다음 화 인식 확인`을 누릅니다.
2. `다음화 무료로 보기`와 `회차 하단 영역도 확인했어요`가 나오는지 확인합니다.
3. 다음 화 자동 이동을 켜고 ▶를 누릅니다. 3초 대기 후 회차가 바뀌는지 확인합니다.
4. 원작소설/추천 카드가 열리지 않는지, 카운트다운 중 터치 정지가 되는지 확인합니다.
5. 일반 `다음화 보기` 버튼은 대상 서비스의 자동 구매를 끄고 무료 접근 가능한 회차에서만 확인합니다. 결제·로그인·광고 시청 안내가 뜨면 자동 처리가 멈춰야 합니다.

이 확인은 실기기에서 아직 완료되지 않았습니다. 인식 결과가 없으면 현재 화면과 진단 문구를 함께 사용해 다음 원인을 좁힙니다.
